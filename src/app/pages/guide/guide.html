Adding a New Entry

Store a new credential — username, password, and a note.

  1. 1 Click "Add Entry" in the top-right of the vault page. A blank row appears at the bottom of the table.
  2. 2 Fill in the Key field — this is your username, email, or any label for this credential.
  3. 3 Enter your Password. Use the ⚡ Generate button to auto-create a strong random password.
  4. 4 Add an optional Description (e.g. "Netflix account" or "Work email").
  5. 5 Click the checkmark ✓ button to save the row.

Entries are saved automatically to your browser's local storage.

Editing & Deleting Entries

Update or remove existing credentials at any time.

To edit an entry:

  1. → Hover over a row to reveal the action buttons.
  2. → Click the pencil ✏️ icon to enter edit mode.
  3. → Modify the Key, Password or Description fields.
  4. → Click Save to confirm, or Cancel to discard changes.

To delete an entry:

  1. → Click the trash 🗑️ icon on a row.
  2. → A confirmation dialog appears. Click Delete to permanently remove the entry.

Exporting Your Vault

Save an encrypted backup of all your passwords to a file.

  1. 1 Click "Export" in the vault toolbar.
  2. 2 Choose a format: .offvault, .csv, or .xlsx. All three are encrypted — the format only affects how they're structured inside.
  3. 3 Enter a Secret Key — a phrase or random string you'll remember.
  4. 4 Enter a Master Password — a separate password for a second layer of security.
  5. 5 Click "Export as .offvault" — your browser downloads the encrypted file.
Important: Store your Secret Key and Master Password separately and safely. If you lose either one, the file cannot be decrypted.

Importing Data

Load entries from a previously exported file.

  1. 1 Click "Import" in the vault toolbar.
  2. 2 Click "Browse file…" and select your vault backup file (.offvault, .csv, or .xlsx).
  3. 3 If the file is encrypted, enter your Secret Key and Master Password (the same ones used during export).
  4. 4 Click "Import" — only entries that don't already exist (matched by key) are added to your vault.
File Sync: When using a browser that supports the File System API (Chrome, Edge), selecting a file enables the Save button — changes sync directly back to the original file.
Unencrypted .csv and .xlsx files can be imported directly without any keys.

Security: Dual-Key Encryption

How Secret Key + Master Password protect your data.

After export, your vault file is encrypted with AES-256-GCM — government-grade encryption. The encryption key is derived from both your inputs combined via PBKDF2 (100,000 iterations).

Secret Key

A memorable passphrase or random string. Think of it as the key to your vault.

+

Master Password

A second independent password. Even if someone gets the Secret Key alone, they still can't decrypt.

↓

AES-256-GCM Encrypted File

Unbreakable without both keys. Safe to store in cloud, email to yourself, or keep on a USB drive.

Best practice: Store the Secret Key and Master Password in different locations — e.g. write one on paper, store the other in a different app.

8

Resetting the Vault

Permanently delete all stored entries and start fresh.

  1. 1 Click the "Reset" button in the vault toolbar (trash icon).
  2. 2 A confirmation dialog shows how many entries will be deleted.
  3. 3 Click "Reset All" to permanently remove everything, or "Cancel" to go back.
Warning: This action is irreversible and immediately clears all entries from browser storage. Export your vault first if you want a backup.
